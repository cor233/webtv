多内核切换

📊

协议兼容

已接入 Force、JianPian、Thunder、TVBus 等 FongMi 协议扩展。

三种内核，一个壳子

针对不同片源和设备场景，选择最合适的解码方式。

EXO

Media3 官方播放器，格式兼容性最好，默认内核。

默认
IJK

软硬解自适应，适合老设备与特殊编码片源。

MPV

更强的音视频滤镜与颜色控制，进阶玩家之选。

安全加固

v5.6.0 依据代码审计结果完成高危项修复。

认证收紧

本地 HTTP 写操作强制 token，播放记录/进度端点纳入保护，DNS rebinding 防护。

SSRF 拦截
